# Data Visualization Project


This code contains the implementation of two data visualizations done for the course [G0R72A] Data Visualisation in Data Science, by Group 16 (Salma Loukili and Tom Segers).
Switch branches to see the different implementations.
17/05/2024


This project visualizes the D.E.A.D. dataset, detailing customer profiles, product transactions, and regional sales performance for a retail environment. The goal is to reveal insights into customer behavior, product trends, and sales by region using interactive, visually engaging charts.

## Key Visualizations
1. **Seasonal Sales Overview**: A circular chart displaying sales, revenue, orders, and delivery times per season, allowing year-by-year analysis to identify seasonal trends in adventure equipment purchases.
2. **Product Pricing by Region**: An interactive map showing product prices by region and quantity purchased, providing insights into regional pricing strategies and sales volumes.

## Technology Stack
- **Framework**: Svelte, HTML, CSS, d3.js, JavaScript
- **Data Processing**: Python for initial dataset cleaning and transformation
